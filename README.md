# Nova Admin Dashboard

Nova is a responsive React and Vite admin dashboard interface for analytics, user management, account settings and reusable application screens.

![Nova dashboard preview](screenshot.png)

## Features

- Responsive fixed sidebar and header with mobile menu
- Dark and light theme support persisted locally
- Dashboard metrics, charts, campaigns and user views
- Account, login, signup, documentation and error pages
- Independent content scrolling with route-aware loading
- Icon-only social and support links in the footer

## Tech stack

React, Vite, React Router, styled-components, MUI, Recharts, React Icons and React Toastify.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
npm run deploy
```

Live site: [Nova Admin Dashboard](https://a2rp.github.io/nova/)
